# 文字塔防 · 编辑器操作说明

> 适用版本：Cocos Creator 3.8.8
> 项目路径：`E:\易游记灵境\文字塔防最新\文字塔防Cocos`
> 功能：在编辑器里配置**关卡**（波次/怪物等级/小怪池/Boss/刷新节奏）、自定义**怪物**与**字塔**数值，并可给两者挂序列帧动画
> 序列帧/动画部分详见同目录《[序列帧与预制体操作说明](./序列帧与预制体操作说明.md)》

---

## 一、总体流程

```
怪物：创建预制体（挂 EnemyConfig 填数值）→ 关卡配置引用
关卡：Canvas → GameApp →「关卡配置（Stages）」逐关编辑波次/小怪池/Boss/节奏
字塔：创建预制体（挂 TowerConfig）→ 「TowerPrefabs」引用，数值/位置覆盖内置
```

**回退规则**：
- 「关卡配置」留空 → 使用代码内置关卡表（Config.ts 的 `STAGE_ROWS`，默认 30001 关 5 波）
- `TowerPrefabs` 留空 → 所有字塔用内置数值（`TOWER_STATS`）和内置位置（`TOWER_POSITIONS`）
- 只要配置了至少一关，就**完全替换**内置关卡表

## 二、创建怪物预制体（小怪 / Boss 通用）

### 1. 新建节点
1. 打开场景 `assets/Main.scene`
2. **层级管理器**空白处右键 → **创建 → 节点**（空节点即可，外观默认由代码绘制）
3. 命名，如 `敌人-火鬼`、`Boss-魔`

### 2. 挂 EnemyConfig 组件
选中节点 → 检查器 → **添加组件 → 自定义脚本 → EnemyConfig**：

| 字段 | 类型 | 说明 | 参考值 |
|---|---|---|---|
| displayName | 文本 | 名称 | 火鬼 |
| hp | 数值 | 生命值（1 级基准，等级会再缩放） | 小怪 10 / Boss 100 |
| atk | 数值 | 攻击力（对城堡伤害，等级会再缩放） | 小怪 2 / Boss 10 |
| speed | 数值 | 移动速度 | 0.8 |
| range | 数值 | 射程 | 近战 15 / 远程 120+ |
| attackCd | 数值 | 攻击间隔 ms | 2000 |
| size | 数值 | 体型大小（绘制半径） | 8 / Boss 14 |
| color | 颜色 | 怪物圆球颜色 | 自定 |
| isBoss | 勾选 | 是否 Boss | Boss 才勾 |
| bossName | 文本 | Boss 名字（单个汉字，显示在血条上） | 魔 |
| bossSkill | 下拉 | Boss 技能：无 / 溅射 / 穿透 / 召唤 | 召唤 |

> **Boss 说明**：`bossName` 或 `bossSkill` 填了任意一个，就用预制体上的名字/技能/颜色；都没填则用内置"每局轮换 Boss"。
> （可选）想要序列帧外观：再加 **Sprite + Animation** 组件，见《序列帧与预制体操作说明》。

### 3. 存为预制体
节点从层级管理器拖到 **资源管理器** `assets` 文件夹 → 生成 `.prefab` → 删除场景原节点。

## 三、配置关卡（核心）

### 1. 入口
层级管理器选中 **Canvas**（挂 GameApp 的节点）→ 检查器找到 **「关卡配置（Stages）」** → 点 `+` 添加一关。

### 2. 每关字段

| 字段 | 说明 |
|---|---|
| stageId | 关卡 id（如 30001；游戏默认从表里第一关开始） |
| note | 备注（如"第一关就5波"） |
| battleLevels | **波次与怪物等级**列表：每条 = wave（第几波）+ level（怪物等级）；**总波数 = 条目数** |
| monsterPrefabs | **本关小怪池**：拖入小怪预制体（根节点挂 EnemyConfig）；空 = 内置近战 |
| bossWaves | **Boss 出场**列表：每条 = wave（第几波出 Boss）+ bossPrefab（Boss 预制体；空 = 内置 Boss） |
| monsterNumMin / Max | 每次刷新随机出 **几只** 小怪（区间） |
| monsterCdMin / Max | 两次刷新的随机间隔 **ms**（区间） |
| spawnDurationSec | 每波小怪**持续刷新时长**（秒） |
| bossAtSec | Boss 出场时刻（秒，相对本波开始） |

### 3. 运行时机制（配置怎么生效）

每波流程：

```
10 秒准备倒计时
    ↓
波开始 → 前 spawnDurationSec 秒内持续刷小怪：
    每隔随机 [monsterCdMin, monsterCdMax] ms 刷一批，
    每批随机 [monsterNumMin, monsterNumMax] 只，
    从小怪池（monsterPrefabs）里随机选类型
    ↓
（若本波配了 Boss）波开始 bossAtSec 秒后 Boss 発场（带预警圈+提示）
    ↓
刷新时长结束 + Boss 已出 + 场上无怪 → 本波结束 → 三选一奖励 → 下一波
```

**怪物等级缩放**（battleLevel 的 level）：

| 等级 | 生命/攻击倍率 |
|---|---|
| 1 | ×1 |
| 2 | ×1.5 |
| 3 | ×2.25 |
| 4 | ×3.4 |

> 等级只缩放 hp/atk（含预制体上填的数值），移速/射程等不变。

### 4. 示例：第一关（5 波，3/5 波出 Boss）

| 字段 | 填法 |
|---|---|
| stageId | 30001 |
| battleLevels | [1,1] [2,1] [3,1] [4,2] [5,2]（共 5 波，第 4 波起怪升 2 级） |
| monsterPrefabs | 近战小怪预制体、远程小怪预制体 |
| bossWaves | [3, Boss-魔] [5, Boss-兽] |
| monsterNumMin/Max | 1 / 2 |
| monsterCdMin/Max | 1000 / 2000 |
| spawnDurationSec | 30 |
| bossAtSec | 15 |

### 5. 多关卡
「关卡配置」里加多个 StageConfig 即可（每条 = 一关）。游戏默认从第一关开始；目前通关后是胜利结算，关卡连续推进的入口后续再接。

## 四、配置字塔（TowerPrefabs）

字塔的**数值**和**战场位置**也可以在编辑器里改，不想做动画就纯粹当数值配置用。

### 1. 创建塔预制体
1. 场景里新建空节点 → **添加组件 → 自定义脚本 → TowerConfig**：

| 字段 | 类型 | 说明 | 参考值 |
|---|---|---|---|
| charName | 文本 | **汉字名**（如火、炎；与内置字一致才覆盖） | 火 |
| posX / posY | 数值 | 战场内比例位置（0~1，Y 自顶向下） | 0.32 / 0.62 |
| attack | 数值 | 攻击力 | 10 |
| attackCd | 数值 | 攻击冷却 ms | 500 |
| attackFar | 数值 | 射程 | 280 |
| aim | 下拉 | 目标选择：最近 / 最远 | 最近 |
| attackLock | 数值 | 锁定目标数 | 1 |
| splash | 数值 | 溅射半径（0=无） | 0 |
| splashReduce | 数值 | 溅射伤害百分比 | 100 |
| penetrate | 数值 | 穿透额外目标数 | 0 |
| buffEffect | 下拉 | 特效：无 / 中毒 / 冻结 / 攻速光环 / 减速 | 无 |
| buffEffectPara | 数值 | 特效参数（1:每秒最大生命% 2:冻结ms 3:攻速% 4:减速层数） | 0 |
| color | 颜色 | 塔的颜色 | 红色 |
| desc | 文本 | 描述 | 开局保底输出 |

2. （可选）加 **Sprite + Animation** 做序列帧外观
3. 存为 `.prefab`，删除场景原节点

### 2. 挂载
Canvas → GameApp → **TowerPrefabs** → `+` → 拖入塔预制体。

### 3. 效果规则
- `charName` 对应的字塔，数值/位置**覆盖**内置配置（合成字如 炎/冰 也能覆盖）
- 挂了序列帧的塔部署时显示动画节点；没挂的仍代码绘制，但数值生效
- 攻击范围圈、Lv 等级标记始终保留
- 只能覆盖**已有字**（火/水/木/日/人 + 11 个合成字），不能新增全新字

## 五、测试

1. 编辑器顶部点 **预览**
2. 检查控制台日志：`[stage] 编辑器关卡 N 关：...`（配置生效）或 `[stage] 编辑器未配置关卡，使用内置表`
3. 进入战斗观察：
   - 顶栏「第N波 / 共M波」（M = battleLevels 条目数）
   - 每波开始 10 秒倒计时 → 小怪按节奏刷新（数量/间隔在你配的区间内随机）
   - Boss 在 bossAtSec 秒出现，血条显示预制体里填的名字
   - 等级缩放：第 4 波（level 2）的怪明显更肉/更痛
4. 改数值后：保存场景/prefab → 重新预览即可生效（无需重启编辑器）

## 六、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 配置不生效 | 控制台看 `[stage]` 日志；预制体根节点没挂 EnemyConfig 的条目会被忽略并告警 |
| 想恢复内置关卡 | 把「关卡配置（Stages）」清空 |
| 总波数不对 | 总波数 = battleLevels 条目数（不是最大 wave 值），检查条目数 |
| 某波没出 Boss | bossWaves 里该波的 wave 填错，或 bossAtSec 大于本波实际时长（Boss 还没到出场点波就结束了） |
| Boss 用的是内置轮换 | Boss 预制体里 bossName 和 bossSkill 都为空 |
| 小怪池配置了但不刷 | 预制体未挂 EnemyConfig（回退内置近战并有告警）；小怪池里混入了勾 isBoss 的预制体会被过滤 |
| 塔属性/位置没覆盖 | charName 和内置字不一致；或 TowerPrefabs 没挂该预制体 |
| 塔的序列帧不显示 | 预制体没加 Sprite 或 Animation 的 Default Clip 为空 / 未勾 Play On Load |
| 改了 prefab 没生效 | 确认改的是 prefab 本体（双击进入编辑）并保存 |
