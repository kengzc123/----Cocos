一、数据模型总览（三层职责）

一个怪物在游戏里由三层信息组成，数值与外观彻底分离：

层配置位置决定什么对应策划表
① 外观预制体 Assets 里的 Prefab 资产 怪物长什么样（单帧 Sprite 或序列帧 Animation）；不含任何数值 monster 表动画列（预留）
② 怪物数值表 Canvas 节点 → GameApp → monsters 数组 血量 / 攻击 / 攻击范围 / 攻击间隔 / 速度（按类型 × 等级一行一条） monster.xlsx
③ 关卡配置 Canvas 节点 → GameApp → stages 数组 几波、每波怪物等级、小怪池、哪波出哪个 Boss、刷新节奏 stage.xlsx

关联规则一句话：关卡按「波次等级」到数值表查行拿数值，按「类型号」找同名预制体当外观。

提示预制体没配也能跑：怪物直接显示数值表名字文本（如「小近战怪 Lv1」，Boss 显示「近战重甲boss Lv16」并带金圈），颜色按类型区分，正好用来核对导入数据；数值表该类型没配则回退内置数值并打告警日志。

二、准备工作

  1. 用 Cocos Creator 3.8.x 打开工程目录 文字塔防Cocos
  2. 在「资源管理器」双击打开场景 assets/Main.scene
  3. 在「层级管理器」选中 Canvas 节点（挂 GameApp 组件的那个）
  4. 右侧「属性检查器」向下滑，能看到两个数组属性：关卡配置（stages） 和 怪物数值表（monsters），以及「字塔预制体配置」——本文只涉及前两个
注意不要运行 gen_project.js，它会重写场景并清空编辑器里配置的数据。

三、配置怪物外观预制体

3.1 命名规则（重要）

预制体文件名 = 怪物类型号，这是自动配对的依据：

类型号怪物预制体文件名
201小近战怪201.prefab
202小远程怪202.prefab
204高速小怪204.prefab
205坦克小怪205.prefab
211 ~ 220十个 Boss211.prefab … 220.prefab

3.2 制作步骤（以 201 为例）

  1. 在场景里新建空节点，命名为 201
  2. 挂外观：加 Sprite 组件拖入单帧图片；序列帧则再加 Animation 组件并勾选 Play On Load
  3. 不需要挂任何脚本组件（数值不读预制体）
  4. （可选）建议放到 assets/resources/enemies/ 目录下，与后续批量导入的约定一致
  5. 把节点从层级管理器拖回资源管理器存为预制体，然后从场景里删掉该节点
提示同一类型的所有等级共用一个预制体——201 的 Lv1 和 Lv100 长一样，只是数值不同。血条、状态圈由代码绘制，不用做进预制体。

四、配置怪物数值表（monsters）

数组里每个条目 = monster.xlsx 的一行 = 某类型某等级的数值。新条目默认值即 201 Lv1 的表值。

4.1 字段说明

字段含义约束 / 默认
type怪物类型号201/202/204/205 小怪；211~220 Boss
level怪物等级1~100；monsterId 自动 = type×100+level
displayName备注名如「小近战怪 Lv1」，仅日志显示
isBoss是否 BossBoss 类型务必勾上
attack攻击力（对城堡每次伤害）≥0
attackFar攻击范围（像素，与战场坐标 1:1）近战约 10，远程 200
attackCd攻击冷却（ms）≥200
blood血量≥1
speed移动速度运行时 ×60 px/s；小怪 1~6，Boss 2
buffTarget / buffEffect / buffEffectParabuff 三列已导入暂不生效，仅打日志，先照表填即可

五、配置关卡（stages）

数组每个条目 = stage.xlsx 的一行 = 一个关卡。新条目默认模板即第 1 关的形状。

5.1 字段说明

字段对应表列说明
stageId / notestageId / 备注关卡 id（30001 起）与备注
battleLevelsbattleLevel波次+等级列表，条目数 = 总波数；等级对小怪和 Boss 同时生效
monsterPoolmonsterType小怪池：每条 = type（数值）+ prefab（可选外观预制体）
bossWavesboss每条 = 波次 + Boss 类型（211~220）+ 可选外观预制体；清空 = 本关无 Boss
monsterNumMin / MaxmonsterNum单次生成数量区间（随机取）
monsterCdMin / MaxmonsterCd两次生成间隔区间 ms（随机取）
spawnDurationSectime[0]每波小怪刷新持续时长（秒）
bossAtSectime[1]Boss 出场时刻（秒，相对本波开始）；无 Boss 的波忽略

5.3 示例：第 2 关（30002，第 5 波出 Boss 211）

在 30001 基础上改：battleLevels 换成 Lv 4/7/10/13/16；bossWaves 留 1 条（wave=5, type=211, prefab 拖 211 预制体）；monsterCd 改 990/1980；bossAtSec=15。同时确认数值表已有 211 Lv16 行（见 4.3）。

提示进游戏默认打关卡数组第一条；要测别的关，把目标关拖到数组首位即可。

验证清单

  • 启动日志显示数值表行数与所配行数一致，无「缺行/回退」告警
  • 第 1 关 5 波：怪物血量逐波变厚（10→13→16→20→25）
  • 拖了预制体的类型，场上显示预制体画面；没拖的显示名字文本（如「小近战怪 Lv13」）+ 血条
  • 每波开始有 10 秒准备倒计时；波内每 1~2 秒刷 2~3 只小怪，持续 30 秒
  • 清完场自动进下一波；5 波打完结算胜利
  • 胜利结算出现「下一关 / 主页」双按钮；点下一关直接进 30002；主页开始按钮上方显示「当前关卡：第2关」

关卡进度（连胜机制）

机制通关进度存在本地（sys.localStorage，key wztd_progress_v1），重启游戏不丢：
  • 主页关卡选择：关卡网格（每页 15 个，可翻页）——绿色「✓ 已通关」可点，青色「未通关」当前解锁关可点，带锁图标的未解锁（需先过前一关）；点选后按「开始战斗」进入
  • 胜利 → 记录该关已通关，结算弹窗出现「下一关 / 主页」双按钮（当前是最后一关时只有「返回主页」）
  • 失败 → 「重新开始」重打当前关（进度不变）
  • 回主页 → 默认选中最新解锁关；之前的通关关卡随时可回头再打
  • 关卡顺序按关卡表（stages）排列顺序，与 stageId 升序一致

测试想重置进度：预览控制台执行 cc.sys.localStorage.removeItem('wztd_progress_v1') 后刷新。

七、常见问题

Q1：怪物刷出来显示的是名字文字，不是我的预制体？

名字文本 = 未配预制体时的默认显示。检查关卡 monsterPool / bossWaves 条目里 prefab 槽是否拖入了预制体；type 只决定数值，外观必须在该条目的 prefab 槽拖入。

Q2：日志报「就近取 LvX」？

关卡波次等级在数值表里没有对应行。两个选择：按 monster.xlsx 补该行；或不管它（就近向下取值也能跑，但数值偏弱）。

Q3：Boss 不出来？

依次检查：① bossWaves 有条目且波次号 ≤ 总波数；② 数值表里该 Boss 类型的 isBoss 已勾选；③ bossAtSec 小于本波实际时长；④ boss 条目的类型号写对（211~220，老表的 203 已废弃）。

Q4：attackFar 填多少？

按表填，单位像素，战场坐标 1:1：近战怪与多数 Boss 填 10（贴脸才打），远程怪与远程 Boss 填 200（离很远就停下攻击）。

Q5：speed 数值好小（3、2），对吗？

对。表值按「每帧位移」记录，运行时自动 ×60 换算成 px/s。小怪 1（坦克）~6（高速），Boss 2。

Q6：编辑器里改了数据没生效？

确认改的是场景里 Canvas 上的属性并已保存场景（Ctrl+S），然后重新点预览运行。游戏运行中改属性不会热更。

Q7：之前配过的关卡数据丢了？

本轮改版字段有更名（monsterPrefabs → monsterPool、Boss 由预制体改为类型号），旧数据不兼容需按新结构重配一次；或运行过 gen_project.js 重置了场景。

八、批量导入（已实现，双击即用）

操作步骤

  1. 策划表放 表格\stage.xlsx 和 表格\monster.xlsx（保持原格式：第1行英文表头、第2行中文说明、第3行起数据）
  2. 双击项目根目录 导表.bat（首次运行自动装依赖；也可命令行 node tools\export_tables.js）
  3. 看到「√ 已写出 …stages.json / monsters.json / 导表报告.html」即成功；校验有 error 时会指出哪关哪行，修表后重跑
  4. 回到 Cocos Creator 等资源刷新，运行游戏，控制台出现 [import] json 生效：50 关 + 1400 行怪物数值 即生效；主页关卡网格自动变为 50 关（4 页）

产物与优先级

  • assets/resources/stages.json + monsters.json：运行时自动预载；导表报告.html 双击查看导入摘要与警告
  • 优先级：json 基表 > 编辑器同 id 覆盖 > 内置表——编辑器里手动配的关卡/怪物行按 stageId / (类型,等级) 覆盖 json 对应条目，用于临时调参；清空编辑器数组则完全用 json
  • 未导入 json 时控制台提示「未找到导表 json」，自动回退编辑器/内置数据，不影响运行
  • 怪物外观预制体放 assets/resources/enemies\ 目录，文件名 = 类型号或怪物名自动绑定（201.prefab、211.prefab、小近战怪.prefab 均可）
  • buff 三列（buffTarget / buffEffect / buffEffectPara）已导入暂不生效，刷新怪物时控制台打 [buff] 未生效 … 日志
  • Excel 千分位坑：填「660,1320」若 Excel 存成了数字 6601320，导表自动按 660,1320 修复并给警告（已在 30035 关遇到）
