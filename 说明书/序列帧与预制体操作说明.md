# 文字塔防 · 序列帧与预制体操作说明

> 适用版本：Cocos Creator 3.8.8
> 相关脚本：
> - `assets/scripts/EnemyConfig.ts`（怪物数据 + 序列帧）
> - `assets/scripts/TowerConfig.ts`（字塔数据 + 序列帧）
> - `assets/scripts/GameApp.ts`（编辑器配置入口）
> - `assets/scripts/BattleView.ts`（实例化与渲染同步）

---

## 一、能做什么

字塔和怪物都可以改用**预制体 + 序列帧动画**来渲染，数值也改在编辑器里配置：

| 对象 | 可配置数据 | 序列帧效果 |
|---|---|---|
| **怪物** | 生命 / 攻击 / 移速 / 射程 / 体型 / 颜色 / 攻击间隔 / Boss 名字与技能 | 行走/待机/受击动画 |
| **字塔** | 攻击 / 冷却 / 射程 / 目标选择 / 锁定数 / 溅射 / 穿透 / 特效 / 位置 | 燃烧/流水/发光等循环动画 |

**核心规则**：
- 有预制体 → 代码自动 `instantiate` 节点并播放动画，不再画默认圆球/文字
- 没预制体 → 完全走原来的代码绘制，**不影响已有功能**
- 一个项目可以混用：部分字塔用序列帧，部分不用

## 二、怪物序列帧

### 1. 准备动画资源

把序列帧图片放进 `assets` 文件夹：
- 可拖零散 PNG（如 `walk_01.png` ~ `walk_08.png`）
- 也可以打图集（SpriteAtlas）

### 2. 创建动画剪辑

1. 资源管理器右键 → **创建 → 动画剪辑**，命名如 `小怪-行走`
2. 双击打开 **动画编辑器**
3. 把帧图依次拖到时间轴上，设置：
   - **Sample（采样率）**：例如 `8` 表示 8 帧每秒
   - **WrapMode（循环模式）**：`Loop` 循环播放
4. 保存动画剪辑

### 3. 给怪物预制体加外观

1. 找到已有的怪物预制体（如 `enemy1.prefab`），**双击进入预制体编辑模式**
2. 检查器 → **添加组件 → 渲染器 → Sprite**（2D 精灵）
   - SpriteFrame 拖入第一帧图
   - Size Mode 建议 `CUSTOM`，手动设置宽高
3. **添加组件 → 动画 → Animation**
   - **Default Clip**：拖入刚建的动画剪辑
   - 勾选 **Play On Load**（运行时自动播放）
4. 检查器顶部点 **保存**，退出预制体编辑

> 注意：EnemyConfig 组件继续保留在同一节点上，数据配置不受影响。

### 4. 在波次里使用

配置 `GameApp` 的 `WaveEntries` 时，引用该怪物预制体即可。刷怪时引擎会自动：
- 读取 EnemyConfig 的战斗数值
- 实例化节点并播放动画
- 每帧同步怪物位置
- 怪物死亡或重开局时销毁节点

## 三、字塔序列帧

### 1. 创建塔预制体

1. 在场景里新建空节点，命名如 `塔-火`
2. 挂 **TowerConfig** 组件（检查器 → 添加组件 → 自定义脚本 → TowerConfig）
3. 填写字段：

| 字段 | 说明 | 参考值 |
|---|---|---|
| charName | 汉字，如 `火` | 火 |
| posX | 战场内 X 比例位置 | 0.32 |
| posY | 战场内 Y 比例位置（自顶向下） | 0.62 |
| attack | 攻击力 | 10 |
| attackCd | 攻击冷却 ms | 500 |
| attackFar | 射程 | 280 |
| aim | 目标选择：最近 / 最远 | 最近 |
| attackLock | 锁定目标数 | 1 |
| splash | 溅射半径（0=无） | 0 |
| splashReduce | 溅射伤害百分比 | 100 |
| penetrate | 穿透额外目标数 | 0 |
| buffEffect | 特效类型：无 / 中毒 / 冻结 / 攻速光环 / 减速 | 无 |
| buffEffectPara | 特效参数 | 0 |
| color | 颜色 | 红色 |
| desc | 描述 | 开局保底输出 |

> **重要**：`charName` 必须和你要替换的汉字完全一致（如 `火`、`炎`），系统会按这个名字覆盖内置数值。

### 2. 加序列帧动画

同怪物步骤：加 Sprite + Animation 组件，Default Clip 设循环动画，勾 Play On Load。

### 3. 存为预制体并挂载

1. 把节点拖到 `assets` 文件夹生成 `.prefab`
2. 删除场景里的原节点
3. 选中场景里的 **Canvas**，在检查器找到 **TowerPrefabs**
4. 点 `+` 添加一条，把塔预制体拖进去

### 4. 效果

- 部署该字塔时，自动出现序列帧节点并播放动画
- 不画默认底座和文字
- 攻击范围圈、等级标记（Lv）仍然显示
- 塔的数值、位置按 TowerConfig 覆盖内置配置

## 四、只改数值、不用序列帧

如果你只想调整属性，不想做动画：

- **怪物**：EnemyConfig 该填的照填，不加 Sprite/Animation 即可
- **字塔**：TowerConfig 填好数值，不加 Sprite/Animation 即可

这样运行时仍然用原来的 Graphics 绘制，但数值已经按你的配置生效。

## 五、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 怪物/塔没显示序列帧 | 预制体没加 Sprite 或 Animation 的 Default Clip 为空；或未勾 Play On Load |
| 动画不循环 | 动画剪辑 WrapMode 不是 Loop |
| 塔位置不对 | 检查 TowerConfig 的 posX/posY（0~1 比例值），不是像素坐标 |
| 塔属性没生效 | charName 与内置字不一致，或 TowerPrefabs 没挂该预制体 |
| 怪物数值没生效 | 预制体没挂 EnemyConfig，或 WaveEntries 没引用该预制体 |
| 只想恢复默认绘制 | 从 TowerPrefabs / WaveEntries 移除对应条目即可 |
